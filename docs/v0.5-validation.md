# BT-MCP v0.5 验证报告

对应版本：v0.5.0 · 报告日期：2026-11-11

## 1. 这一版验证体系的变化

v0.4 建立了四层验证（差分 / 结构 / golden / 官方 SDK）。v0.5 在其上加了
**故障注入**与**随机 L5 输入**两层，并把「配置矩阵」纳入差分。

| 层 | 手段 | 规模（v0.5） | 回答的问题 |
|---|---|---|---|
| L1 | C ↔ 独立 Rust oracle 差分 | **1295**（主 1045 + FCS16 配对 196 + 共享模式 54） | 两份实现是否逐字节一致 |
| L2 | 结构符合性 `test_conformance.c` | 64 | 是否符合 MCP 规范结构 |
| L3 | golden transcript（人工核规范） | 20 | 字节是否非预期漂移 |
| L4 | 官方 MCP TS SDK 1.32.2 互验 | 38 | 第三方能否真正理解输出 |
| L5 | 故障注入 `test_fault.c` | 21 | 失败时是否正确传播错误 |
| L6 | L5 随机输入 `test_l5_fuzz.c` | 3（30 万输入） | 畸形输入是否永不崩溃 |
> 注（v0.6 整理）：`test_threads.c` 已被 `test_stress.c`（4×4 + 断链重连 + 池分派）
> 取代并删除；`test_l5_fuzz.c` 已被 `fuzz/fuzz_l5.c`（结构变异 + 四条不变量）取代并删除。

| 附加 | 有损通道 / TSan / 覆盖率 | 17 / 10 / 门禁 | ARQ 收敛 / 并发安全 / 不倒退 |

## 2. 战果：这一版抓到的 5 个真缺陷

| # | 缺陷 | 由谁发现 | 影响 |
|---|---|---|---|
| 1 | `mcp_client.c` 两个 8KB **模块级**缓冲 | 代码审计（TSan 用例设计时） | 桥接同时连多台设备互相覆盖 |
| 2 | `ping` 响应不是空对象（回了 `{"pong":true}`） | L3 golden 人工核规范 | 不符合 MCP 规范 |
| 3 | writer 在 `sink == NULL` 时**解引用崩溃** | L5 故障注入 | 畸形调用直接段错误 |
| 4 | `client_call_tool` / `read_resource` 缺 `!c` 校验 | 边界测试 | 传 NULL client 崩溃 |
| 5 | JSON 取值器缺输出指针校验 | L6 语料 | 传 NULL 输出指针崩溃 |

另有 **1 个集成缺陷**由 L4 抓出：mock 的 `pipe` 传输把 L3 的**分片**当成独立
JSON 写出，官方 SDK 收到半截消息（`Unterminated string at position 238`）——
必须在传输边界做重组。

以及 **2 个语义收紧**由 L6 抓出：解析器原本接受尾随垃圾（`{"a":1}xyz`）与
尾随逗号（`{"a":1,}`）。帧长度本已界定消息边界，尾随字节意味着报文损坏，
现改为严格拒绝（oracle 同步镜像）。

## 4. 未达标项（如实记录）

**V3 分支覆盖率：目标 75%，实际 67.05%。**

未达标的原因已定位清楚，不是「有分支忘了测」，而是：

1. `mcp_server.c` 有 **432 个未覆盖分支**，集中在「方法 × 参数形态 × 失败点」
   的组合空间（11 个方法 × 7 种参数形态 × 6 个失败点 ≈ 460 组合），
   手写用例不可行；
2. 另有若干**防御性 NULL 检查**（v0.5 刚加的 fail-closed 守卫），
   正常路径永远不会触发，需要逐点构造。

本版投入了 4 套测试（197 项）把分支从 57.9% 推到 67.1%（+9.2pp），
分文件看：writer 64.6%→75.5%、session 69.1%→70.5%、json 73.3%、
frame 68.9%、mcp_server 63.8%。

**补齐路径已写入 v0.6 N1**：表驱动组合矩阵（自动生成方法×形态×失败点的
笛卡尔积），预计可一次跨过 75%。

覆盖率门禁按「防回归」设为 **94/66**（略低于实测），
**不用未达成的目标值当门禁**——否则 CI 永远红，等于没有门禁。

## 5. 复现命令

```sh
./build.sh                    # 全量（默认 200 轮）
./build.sh 400                # 加大随机轮数

# 官方 SDK 互验
cd tests/sdk_interop && npm install && node sdk_interop.mjs ../../build/btmcp_mock

# 覆盖率门禁
./tools/coverage.sh

# 消毒器
./build.sh 100 asan
BT_MCP_TSAN=1 ./build.sh 60

# 共享模式（RAM 优化验证）
cc -O2 -std=c99 -DBT_MCP_CFG_SHARED_REASM=1 -Icore/include \
   tests/test_shared_reasm.c core/src/frame.c core/src/trace.c -o /tmp/t && /tmp/t
```
